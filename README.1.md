# Q2 — CO2: Bash Automation Scripts

## How to run
Open a Linux terminal in the repository:
```bash
chmod +x ShellScripts/*.sh
./ShellScripts/system_report.sh
./ShellScripts/backup_folder.sh /path/to/source /path/to/backup
./ShellScripts/file_organizer.sh /path/to/test-folder
```

Try the file organizer only on a test folder with copies of files. It moves files into extension-based folders.

Capture terminal screenshots for each script run in `Screenshots/`.
