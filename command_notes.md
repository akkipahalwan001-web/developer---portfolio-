# Linux Command Notes

| Command | Purpose |
|---|---|
| `pwd` | Shows the current working directory |
| `whoami` | Prints the current username |
| `date` | Shows current date and time |
| `uname -a` | Displays kernel/system details |
| `cat /etc/os-release` | Displays Linux distribution details |
| `ls -la` | Lists files, including hidden files, with details |
| `df -h` | Shows disk usage in readable units |
| `free -h` | Shows memory usage in readable units |
| `ip addr` | Displays network interfaces and addresses |
