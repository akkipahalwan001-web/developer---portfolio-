# Personal Learning Roadmap
## Aalekh Gupta | B.Tech CSE (AI & ML), SOET | K.R. Mangalam University | 2026–2030

> **Direction:** AI/ML with Full-Stack foundations — build useful software, understand data, and gradually turn models into real applications.

## Semester 1 — Foundations (Current)
**Focus:** Programming fundamentals, problem solving, basic electronics, and developer workflow.

- **Skills being developed:** Python fundamentals (variables, data types, conditionals, loops, functions, collections), HTML structure, introductory Arduino/embedded concepts, debugging, documentation, and teamwork/presentation.
- **Tools used:** Python, Arduino IDE / Arduino-compatible coding environment, Arduino Uno, breadboard, sensors and servo motors, Git, GitHub, VS Code / code editor, browser developer tools.
- **Milestone — DeveloperPortfolio:** Create a documented GitHub repository, a one-page technical resume, this roadmap, and a responsive GitHub Pages website. Practice commits with clear messages and maintain evidence/screenshots.
- **Project milestone:** Reverse Recycling Vending Machine prototype: bottle detection and acceptance/rejection logic, sensor-based input, servo mechanism, and reward concept. Document the prototype honestly, including what is implemented and what is still planned.

## Semester 2 — Core Computer Science + Web Basics
**Focus:** Become more confident writing programs and build small end-to-end web applications.

- Learn **Data Structures & Algorithms**: arrays/lists, strings, stacks, queues, linked lists, searching, sorting, recursion, and basic time-complexity analysis.
- Learn **Database fundamentals**: relational concepts, SQL, tables, keys, joins, CRUD operations, and basic database design.
- Learn **Web basics**: HTML, CSS, responsive design, JavaScript fundamentals, DOM, forms, and simple API concepts.
- Use Git/GitHub consistently: branches, pull requests, issues, README files, and project releases.
- Build 2 small projects: a CRUD app backed by a database, and a responsive web app with JavaScript.
- **Planned certification by end of Semester 2:** *freeCodeCamp Responsive Web Design Certification* (complete the curriculum and projects; verify current certification requirements on freeCodeCamp before claiming completion).

## Semester 3 — Python + Data Foundations
- Strengthen Python with modules, file handling, exceptions, OOP, virtual environments, and testing basics.
- Learn NumPy, Pandas, data cleaning, visualization, and introductory statistics.
- Practice DSA weekly and solve beginner/intermediate programming problems.
- Build a data analysis project using a clearly documented dataset.

## Semester 4 — Machine Learning Foundations
- Learn supervised and unsupervised learning, train/test split, validation, evaluation metrics, feature engineering, and model limitations.
- Study linear algebra, probability, statistics, and calculus concepts needed for ML.
- Use scikit-learn and notebooks; create reproducible experiments.
- Build and publish a small ML project with a clear problem statement and evaluation.

## Semester 5 — AI/ML + Full-Stack Integration
- Explore neural-network fundamentals and deep learning with one framework (PyTorch or TensorFlow).
- Learn APIs (e.g., Flask/FastAPI), authentication concepts, and deploy a simple model-backed app.
- Improve frontend skills and build an application that connects a user interface, API, and model/data layer.
- Learn responsible AI basics: privacy, bias, limitations, and safe use.

## Semester 6 — Specialisation and Deployment
- Select a focus area based on projects and coursework: applied ML, computer vision, NLP, or data science.
- Learn Docker fundamentals, CI/CD basics, cloud deployment concepts, monitoring, and logging.
- Build a more complete portfolio project with tests, documentation, and a deployed demo.

## Semester 7 — Internship / Research Preparation
- Prepare a targeted resume and portfolio; practise technical interviews and communication.
- Apply for internships, contribute to beginner-friendly open-source issues, and seek faculty-guided projects.
- Build one substantial project with measurable results and a clear technical write-up.

## Semester 8 — Capstone and Career Readiness
- Complete a final-year project with a defined problem, methodology, evaluation, and demonstration.
- Polish GitHub repositories, portfolio, LinkedIn, resume, and project demos.
- Review DSA, CS fundamentals, ML fundamentals, and interview topics; plan postgraduate or entry-level pathways.

## Habits and checkpoints
- Code regularly and keep a weekly learning log.
- Every semester: finish at least one project, write a useful README, make meaningful commits, and review the roadmap.
- List skills only when comfortable explaining and demonstrating them. Mark certifications/projects as completed only after actually completing them.
