# Git Commands Used in Q3

```bash
git init
git status
git add .
git commit -m "Add API interaction and portfolio files"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/DeveloperPortfolio.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username and use the actual repository URL. If the remote is already configured, skip `git remote add origin`.
